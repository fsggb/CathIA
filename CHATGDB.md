# CathIA : conception 3D pour le froissartage

Site : https://fsggb.github.io/CathIA/ . Application web de conception 3D pour le froissartage (construction scoute en bois) : traverses, tenons, mi-bois, filets ; mise en plan cotée avec nomenclatures ; bibliothèques de modèles ; montage pas à pas.

- Les projets de chaque utilisateur sont enregistrés dans son propre Google Drive (accès limité aux fichiers créés par CathIA).
- Une version Google Apps Script existe en parallèle ; la version GitHub Pages est recommandée (chargement plus rapide).
